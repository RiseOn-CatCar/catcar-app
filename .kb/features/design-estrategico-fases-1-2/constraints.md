# Constraints — design-estrategico-fases-1-2

Contrato mecânico entre arquitetura e implementação. Linhas imutáveis após citação; qualquer superseded vira nova linha apontando para a rationale de supersessão.

| ID | Kind | Severity | Rule | Source | Added |
|---|---|---|---|---|---|
| CON-001 | forbidden_dependency | block | `src/Contexts/Atendimento/**` must not import types from `src/Contexts/CatalogoEstoque/**`, `src/Contexts/Comunicacao/**` or `src/Contexts/Identidade/**` (cross-BC types cross the boundary only through `src/Contracts/**` or `Integrations/*Acl`). | `design.md#ddd-context-map` | 2026-06-07 |
| CON-002 | forbidden_dependency | block | `src/Contexts/<BC>/**` must not import EF Core (`Microsoft.EntityFrameworkCore.*`) outside of its own `Infrastructure/` and `Integrations/` folders. | `design.md#architectural-pattern` | 2026-06-07 |
| CON-003 | forbidden_dependency | block | `src/SharedKernel/**` must not reference any `src/Contexts/**` namespace, must not contain entity framework types, validators, or domain enums with business semantics. | `design.md#shared-kernel` | 2026-06-07 |
| CON-004 | required_pattern | block | Each bounded context must live under its own module folder (`src/Contexts/<BC>/`) with subfolders `Domain/`, `Features/<UseCase>/`, `Infrastructure/`, `Integrations/` (last only for `Atendimento` and `Identidade` consumers). | `design.md#architectural-pattern` | 2026-06-07 |
| CON-005 | required_pattern | block | Each vertical slice must be a folder under `src/Contexts/<BC>/Features/<UseCase>/` containing at least `Command` (or `Query`), `Handler`, `Validator` and `Endpoint` files. No slice may be split across technical folders (`Services/`, `Controllers/`, `Repositories/`). | `design.md#architectural-pattern` | 2026-06-07 |
| CON-006 | data_boundary | block | Each bounded context must use its own PostgreSQL schema (e.g. `atendimento`, `catalogo_estoque`, `comunicacao`, `identidade`). A cross-BC `DbContext` is forbidden. | `design.md#ddd-context-map` | 2026-06-07 |
| CON-007 | required_pattern | block | Cross-BC communication must go through Wolverine handlers. Direct method calls between BCs (i.e. `Contexts/Atendimento` calling into `Contexts/CatalogoEstoque`) are forbidden. | `design.md#module-interactions` | 2026-06-07 |
| CON-008 | required_pattern | block | Domain events that cross a bounded context must be published through Wolverine's outbox in the same database transaction as the aggregate mutation. Direct in-process `EventBus.Publish(...)` without outbox persistence is forbidden for integration events. | `design.md#resolved-open-questions` | 2026-06-07 |
| CON-009 | required_pattern | block | Anti-corruption layers (ACLs) must live inside the downstream BC, in `src/Contexts/<DownstreamBC>/Integrations/`, not in the upstream BC. ACL classes must translate upstream DTOs/contracts into downstream domain types. | `design.md#anti-corruption-layers` | 2026-06-07 |
| CON-010 | api_contract | block | All HTTP endpoints must be exposed as ASP.NET Core Minimal APIs under `src/Api/Endpoints/<BC>/<UseCase>Endpoint.cs`, mapped via a single `MapGroup` per BC. No MVC controllers. | `design.md#stack` | 2026-06-07 |
| CON-011 | api_contract | block | The OpenAPI/Swagger document must be generated from code (Swashbuckle or built-in OpenAPI in .NET 10), published at `/swagger`, and must include the auth scheme description. | `design.md#stack` | 2026-06-07 |
| CON-012 | required_pattern | block | Every domain entity must extend `Entity<TId>` from `SharedKernel` and expose a private constructor for ORM. Public constructors must require all required fields and apply invariants. | `design.md#shared-kernel` | 2026-06-07 |
| CON-013 | required_pattern | warn | Tests for domain code (aggregates, value objects, domain services) must be written test-first and live under `tests/Contexts/<BC>.Tests/Domain/`. Integration tests must use Testcontainers for PostgreSQL. | `design.md#module-interactions` | 2026-06-07 |
| CON-014 | performance_budget | warn | p95 latency for any OS state-transition endpoint must be < 250 ms under the test load defined in the quality feature. | `design.md#risks` | 2026-06-07 |
| CON-015 | compatibility_window | block | Target framework must be `net10.0`. Adding a new top-level package to the solution requires a record in `versions.props` with the pinned version. | `design.md#stack` | 2026-06-07 |
